# KEYS PRD 0.2

> File path retained for compatibility; this document now reflects the v0.2 concept lock.

## User promise

**Financial independence shouldn't happen all at once.**

A young person should be able to understand markets, practice safely, and then act freely inside explicit financial boundaries without asking for permission on every in-bounds action.

## Primary Stocklana wedge

A teen and guardian use KEYS Family for bounded tokenized-stock autonomy.

The guardian defines the current Mandate. Maya acts freely inside it. A boundary-crossing action is refused or escalated. Wider standing authority requires an explicit guardian-signed transition.

## Main user journey

1. Family relationship / Charter exists.
2. Maya sees her **current key** in plain language: allowed assets/actions, limits, expiry and what requires a request.
3. Contextual learning appears only when useful: unfamiliar asset/action, Practice, boundary refusal, market-condition change or review.
4. Maya performs an in-bounds action.
5. KEYS verifies Mandate + required market evidence and **ALLOWs immediately**.
6. Maya attempts an out-of-bounds action.
7. KEYS **REFUSEs** in the execution path or offers a boundary request.
8. Maya may commit a short pre-outcome request with an optional market invalidation condition.
9. Guardian chooses: allow once, widen standing Mandate, or refuse.
10. A standing widen is an explicit signed transition; version/nonce advances and old authorization material becomes stale.
11. Pyth may price, restrict, expire or contextualize an action/request; it never grants authority.
12. Practice and contextual learning remain available throughout without becoming a score.

## Product invariants

- Proposal is not authority.
- Evidence is not maturity.
- Profit is not decision quality.
- Silence is not consent.
- UNKNOWN is not eligible.
- Practice is not custody.
- Learning completion is not authority.
- Market evidence may restrict/expire/escalate, never grant/widen human authority.
- Old authorization material cannot survive a new Mandate version/nonce.
- A token balance is not automatically conventional shareholder title.
- Minor private data / free-form reasoning is not public-chain data.

## v0.2 technical success criteria

The demo must prove, truthfully:

1. one in-bounds action can execute without guardian approval;
2. one out-of-bounds action fails in the Solana execution path;
3. the same action can become executable only after an explicit authorized Mandate change;
4. old authorization material fails after version/nonce change;
5. signed market evidence can be used in a load-bearing condition and fails closed when stale/unknown;
6. no learning or market score auto-widens authority.

## Learning success criteria

A non-technical user should understand:

- what the asset/action means;
- what Maya can do now;
- why a boundary exists;
- what changed in the market if an action becomes stale;
- how to request more freedom;

without completing a course or writing an essay for ordinary in-bounds actions.
